2. 비트세이버 설치
   - 추천 버전을 설치하자
   - 최신 버전에서는 모드가 아직 출시되지 않은 경우가 있으니 추천 버전을 설치합시다.
   - 추천 버전에서도 원하는 모드가 없다면 아래 링크를 참고해서 원하는 버전으로 모딩하면 됩니다.
3. 비트세이버 PC 버전 버전 별 모드 리스트
   - 버전 추가 -> 연도 선택 -> 추천 버전 선택 -> 다운로드

비트세이버를 구입한 플랫폼 선택 뒤 로그인 하면 다운로드 됩니다.

(Oculus store (PC) = Meta PC 스토어 = Rift 스토어)

3. 모딩 방법
   - 모딩할 비트세이버 선택 -> [모드] -> [설치 및 업데이트]
   - 필요한 모드 선택해서 [설치 및 업데이트] (아래 3-1. 모드 추천)


- BSManager에 없는 모드는 비트세이버 모딩 그룹 디스코드나 깃헙 등에서 찾을 수 있습니다.

- 모드 파일은 여기에 드래그하거나 [설치 및 업데이트 버튼] 오른쪽의 [가져오기] 아이콘 클릭해서 설치



 ### 모드 추천

BSManager에서 설치 가능한 모드 중에서 추천

- 맵 확장 관련 : NoodleExtentions, MappingExtensions, Chroma, Vivify, (Cinema 모드는 아래 설명)

- 커스텀맵 리더보드 : ScoreSaber, BeatLeader (리플레이 지원). 둘 다 설치해도 됨

- 커스텀맵 다운로드 & 관리 : BetterSongSearch, BetterSongList

- 멀티플레이 : BeatTogether, MultiPlayerMirror(선택)

- 노트 JUMP Distance 조정 : JDFixer

- 히트 스코어 커스텀 : HitScoreVisualizer

- 세이버, 노트 커스텀 : CustomSabersLite, Custom Notes

  모델 파일은 BSManager -> 모델에서 다운받거나 ModelSaber 사이트에서 Oneclick(Install) 다운로드 (Oneclick 설정 본문 4-2-1 참고)


등 자신이 원하는 모드를 찾아 설치해 봅시다 


* BSManager에 없는 모드는 비트세이버 모딩 그룹 디스코드의 pc-mods 탭이나 깃헙 등에서 찾을 수 있습니다.
* Cinema 모드는 비트세이버 모딩 그룹 디스코드의 #pc-mods 탭에서 다운 가능. yt-dlp.exe 다운받아서 Libs 폴더에 넣는거는 잊지 말아야합니다.

* 디스코드에서 구 버전 모드 다운 받는 방법 예시
  - 1.40.1 호환 CustomSaberLite 모드는 디스코드의 #rule에서 mod-archive 권한을 받고 #pc-mods-1-40-1에서 다운 가능합니다.



4. 커스텀맵, 플레이리스트 다운로드 방법

4-1. BSManager에서 다운로드 방법
- 커스텀맵 받을 비트세이버 선택 -> [맵] -> [+추가] -> [맵 보기] 에서 다운로드
- 커스텀맵 파일은 여기에 드래그 하거나 [맵 가져오기]로 설치 가능

필터와 정렬 기능을 잘 활용하기

- 플레이리스트는 [맵] -> [재생 목록] -> [추가] -> [재생 목록 보기]에서 다운로드 가능

- 플레이리스트 파일은 더블클릭해서 설치 가능
* 플레이리스트 파일을 드래그해서 넣었다면 플레이 리스트에서 커스텀맵을 다운로드 하거나, 재생목록 동기화 과정이 필요함

4-2. 사이트를 통해 Oneclick 다운로드 하는 방법
4-2-1. Oneclick 다운로드 설정
- BSManager -> [설정] -> 추가 콘텐츠 - OneClick 설치 - [모두 선택]

4-2-2. Oneclick을 지원하는 커스텀맵 사이트들
- BeatSaver
- BeastSaber
- ScoreSaber
- BeatLeader

이 4가지 사이트들 중 마음에 드는 곳에서 커스텀맵을 다운로드합시다. (BeatSaver를 추천합니다.)

다 켜두는것을 추천합니다.


4-3. 게임 내에서 다운로드 & 삭제 하는 방법
모딩하면 기본으로 설치되어있는 MORE SONGS 기능도 있지만 불편합니다.
BSManager에서 아래 모드를 설치 해줍시다.
- BetterSongSearch (게임 안에서 커스텀맵 다운로드)
- BetterSongList (맵 리스트에서 커스텀맵 삭제, 정렬 등 기능 추가)

플레이리스트는 BSManager나 커스텀맵 사이트를 통해서 다운로드 가능


비트세이버 메인 화면 왼쪽 - [BETTER SONG SEARCH]

5. 왜 게임 실행 안됨?
5-1. 메타링크 관련
- 메타 링크 앱에서 기본 OpenXR 런타임을 Meta Quest 링크로 설정

5-2. 스팀링크 관련
- SteamVR 설정에서 기본 OpenXR 런타임을 SteamVR로 설정


5-3. 버데탑 관련
5-3-1. VDXR 사용 시 BSManager에서 게임 실행 안되는 경우 (unity 오류, 메모리 오류)

방법ⓐ. (VDXR 포기) 버데탑 OpenXR Runtime을 automatic으로 두거나 SteamVR로 두면 SteamVR로 실행 됨 (SteamVR 설치 필요)

방법ⓑ.
게임 폴더에서 metadata.config 메모장으로 열어서 oculus를 steam으로 수정하거나 metadata.config 삭제하기 -> BSManager 껐다 켜기
추가로 BSManager -> 실행옵션 -> steam 실행 건너뛰기 체크

방법ⓒ. BSManager에서 게임 실행하지 말고 버데탑 GAMES 탭에서 게임 실행하기
비트세이버 Meta PC 버전의 원본 경로 파일을 모딩된 비트세이버로 교체하기 (그럼 BSManager 실행 안 해도 됩니다.)

* 비트세이버 Meta PC 버전 경로 : %programfiles%\Oculus\Software\Software\hyperbolic-magnetism-beat-saber

* BSManager에 설치된 비트세이버 경로: %userprofile%\BSManager\BSInstances
- 우선 Meta Quest Link 앱에서 Meta PCVR 비트세이버를 설치하고 -> 모딩된 비트세이버로 교체 (덮어쓰기 X)

(버데탑 메뉴 여는 법 -> 왼쪽 컨트롤러 메뉴 버튼 클릭)


방법ⓓ. 비트세이버 게임 폴더의 Best Saber.exe 직접 실행하기

5-3-2. 버데탑 사용 시 BSManager에서 비트세이버 Meta PC 버전 실행 안되는 경우

방법①. BSManager에서 게임 실행하지 말고 버데탑 GAMES 탭에서 게임 실행 하기

방법②. 게임 폴더 들어가서 Beat Saber.exe 직접 실행

 
5-3-3. 버데탑 VDXR 런타임에서 이런 호환 문제도 있다
Alternativeplay 모드에서 VDXR 런타임은 퀘스트 컨트롤러 인식 안되는 문제가 있음.
버데탑 OpenXR Runtime을 Autometic이나 SteamVR로 바꿔주고 SteamVR에서 실행하니 잘 인식 
* 이 처럼 버데탑 VDXR 런타임은 호환성이 좀 구리다는 점 알고 있으면 좋음
